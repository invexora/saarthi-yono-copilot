04 / Prototype Development Approach
System Architecture &
Development Methodology
Layered Architecture

📊 Data Layer

  • Synthetic customer profiles (Faker, Indian locale)
  • Transaction logs with behavioral signal patterns
  • RBI + SBI product docs vectorized in Pinecone

🤖 Agent Layer

  • 4-node LangGraph DAG (GraphState TypedDict)
  • Stateless, parallelizable node functions
  • Dual guardrails: Input (PII) + Output (RBI FPC)

📱 Presentation Layer

  • YONO phone emulator (6 interactive screens)
  • Real-time agent trace console with status visualization
  • 3 switchable customer personas with dynamic data
Development Phases

Phase 1 — Data Synthesis & Knowledge Base

Generated 500+ synthetic customer profiles using Faker. Ingested RBI Fair Practices Code and SBI product documentation into Pinecone vector store for RAG-based retrieval.

Phase 2 — LangGraph Orchestrator

Built the 4-node DAG state machine: Input Guardian → Signal Detection → Neo4j Recommendation → Compliance Gate. Each node operates on a shared GraphState context.

Phase 3 — Interactive YONO Emulator

Developed a full phone simulator with 6 YONO app screens, view routing, dynamic data binding to customer personas, and real-time agentic trace visualization.

Phase 4 — DPDP Compliance Integration

Implemented Right to Erasure (consent toggle purges pipeline), Right to Data Portability (JSON export), and Data Minimization (PII masked at ingestion). Decision tokens generated per authorization.
