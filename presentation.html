04 / Prototype Development Approach
System Architecture &
Development Methodology
Layered Architecture

📊 Data Layer

  • Synthetic customer profiles (Faker, Indian locale)
  • Transaction logs with behavioral signal patterns
  • Synthetic policy fixtures validated against a local active manifest; SBI mapping pending

🤖 Agent Layer

  • 4-node LangGraph DAG (GraphState TypedDict)
  • Stateless, parallelizable node functions
  • Dual prototype guardrails: input masking + deterministic output policy checks

📱 Presentation Layer

  • YONO phone emulator (6 interactive screens)
  • Real-time agent trace console with status visualization
  • 5 switchable customer personas with dynamic data
Development Phases

Phase 1 — Data Synthesis & Knowledge Base

Built a synthetic-data generator and five fixed demo personas. Loaded versioned policy excerpts through a hash-validated local manifest for provenance-bearing retrieval.

Phase 2 — LangGraph Orchestrator

Built the 4-node DAG state machine: Input Guardian → Signal Detection → Neo4j Recommendation → Compliance Gate. Each node operates on a shared GraphState context.

Phase 3 — Interactive YONO Emulator

Developed a full phone simulator with 6 YONO app screens, view routing, dynamic data binding to synthetic customer personas, and a real-time governed decision trace.

Phase 4 — Privacy-Control Prototype

Demonstrates purpose consent, masking, erasure and portability workflows. Reviewed offers require explicit authorization and an idempotent downstream completion reference before success is reported.

05 / Competitive Positioning
From Reactive Help
to Governed Proactive Support

Existing Assisted Journeys

  • Reactive — responds only when asked
  • Customer initiates the interaction
  • Designed for questions, navigation and service completion
  • Remain available alongside Saarthi
  • Actual SBI capabilities must be validated during discovery

Saarthi ✦ (This Solution)

  • Proactive — notices before you ask
  • 4 behavioral signal types from transaction streams
  • Privacy controls: identifier masking, purpose consent, eligible-data erasure, decision tokens
  • Support Mode: blocks all sales for vulnerable customers
  • Nudge Budget: max 2 per 14-day cycle
  • "Why am I seeing this?" explainability accordion
